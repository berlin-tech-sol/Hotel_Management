# Security Policy

Berlin Techs values the contributions of the security research community, and we look forward to working with you to minimize risk to Berlin Techs users.


## Reporting a Security Issue

If you have found a security issue in Berlin Techs, please do not use the issue tracker and don't publish it publicly. Instead, report the security issue to support@qloapps.com or contact Berlin Techs Support. So that we can act on it immediately to avoid as much damage as we can.
